KetabGard is a book search application that allows users to search for and find their desired books.
This project is built with a strong focus on clean code, proper component-based architecture, and standard routing implementation.

Features:

 Search for any book and find relevant results

 Display detailed information for each book

 Clean, scalable, and maintainable component-based architecture

 Client-side routing using React Router

 JavaScript-based data source with no backend

 Simple and responsive user interface

 Used:

 React

 React Router DOM

 HTML5

 Tailwind CSS
